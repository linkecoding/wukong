# Security reporting

This early preview has no formal support window or response-time guarantee. Please reproduce issues on current `main` where practical; do not publish credentials or users' private data.

For a suspected vulnerability, use [GitHub private vulnerability reporting](https://github.com/linkecoding/wukong/security/advisories/new) if available. If it is unavailable, open a minimal issue requesting a private reporting channel, without exploit details, tokens, screenshots of private data or a working attack payload. Wait for a private channel before sending sensitive evidence. No dedicated security email address is currently published.

Useful private reports include the affected version/commit, Android/device versions, prerequisites, impact and minimal reproduction. Use dummy data and your own device. Never test against other users' devices/accounts without authorization. Ordinary task failures belong in the bug-report template.

安全问题请优先使用 GitHub 私密漏洞报告；若未开放，请只提交一个请求私密反馈渠道的简短 issue，不要公开利用步骤、密钥或私人数据。普通任务失败使用 Bug 模板反馈。
