# Cobalt A — native app review

Selected concept A is applied to Android resources, in-app mark, adaptive launcher foreground, notification glyph and public brand exports. Functional primary blue is `#2457D6`; navy text is `#14213B`; cool paper is `#F3F6FC`. Body text, muted text, accent text and input outlines meet the documented contrast targets.

Hallmark pre-emit review: Philosophy 4, Hierarchy 4, Execution 4, Specificity 4, Restraint 5, Variety 4. Native Views retain the existing task/setup routes. No decorative motion or gradients were added. System fonts, focus indicators and 48 dp touch targets are preserved.

## Physical Pixel 6 review

Captured actual ADB screenshots in English and Simplified Chinese: tasks, expanded task options, history, logs, log detail, settings, model setup, advanced model setup, device connection, connection troubleshooting and the example dialog. Each scrollable page has top/bottom captures. Also captured embedded, manual and floating virtual-display states and inspected the adaptive icon on the actual launcher. Private device screenshots remain in ignored local `.tooling/cobalt-review/`; the repository contains selected native View renders with the model key field cleared.

Changes made after review:

- Compact arrow/back action replaces a full-width return button in setup screens.
- API key input keeps password masking while using the app’s normal typeface for its hint.
- Fields have consistent control outlines and a visible blue focus ring.
- Advanced configuration and troubleshooting have explicit collapse labels.
- Example dialogs have padded multiline inputs so useful hints remain readable.
- Virtual navigation and text injection are disabled until manual takeover. Empty text is not sent. Close and send controls have separate spacing.
- Clearing a saved model now requires confirmation.
- Native control and dropdown text adopts the navy/muted palette; Chinese Settings heading matches its purpose.
