# Wukong 0.0.2

A conversation-first Personal Agent for Android, with improved virtual-display controls and more reliable execution evidence.

Demos: [Recipe → timer, floating preview and takeover (40 s, MP4)](https://github.com/linkecoding/wukong/releases/download/v0.0.2/wukong-v0.0.2-cross-app-demo.mp4) · [Calculator (48 s, MP4)](https://github.com/linkecoding/wukong/releases/download/v0.0.2/wukong-v0.0.2-demo.mp4).

- Requests, task cards, live previews, results and follow-ups live in one conversation. A native drawer holds History and Settings.
- Floating virtual previews can be moved, resized and closed. Size and position are remembered; takeover offers evenly spaced Back, Home and Resize controls.
- Execution options now include a searchable starting-app picker. Chinese app branding displays 悟空.
- Embedded QuickJS supports short workflows through `wukong`, with explicit selectors, row context, named waits and desired-state operations.
- Fresh completion checks retain intermediate readings and accepted native-action evidence. A restricted arithmetic checker catches inconsistent explicit basic equations.
- Fixes include empty virtual-display startup, Home navigation, stale selector handling and ticking stopwatch targeting.
- Updated [usage documentation](../getting-started.md), [changelog](../../CHANGELOG.md), [disclaimer](../../DISCLAIMER.md) and [contribution guide](../../CONTRIBUTING.md).

**Downloads:** arm64-v8a for most current phones; universal for other supported CPU architectures. Verify downloads against `SHA256SUMS.txt`. Update an existing production-signed installation in place; debug and release signatures differ.

**Requirements:** Android 11+, Wi-Fi, user-authorized Developer options / Wireless debugging, and your own compatible model API key. Android 10 supports development USB activation only. No root, enabled AccessibilityService or companion app is required.

**Known limits:** early preview, with real-device validation concentrated on Pixel 6 / Android 17. Some apps restrict virtual displays. Model decisions and summaries can still be incorrect; sensitive-action detection is heuristic. OCR is local, while relevant task/UI content and requested screenshots go to the configured model provider. API usage may incur provider charges. See [actual task validation](../real-world-validation.md).
