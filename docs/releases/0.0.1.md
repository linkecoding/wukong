First public preview of Wukong, an Android AI phone agent.

- Built-in wireless ADB activation; no root, enabled AccessibilityService, or companion app.
- Focused file, web and in-app search examples, guided setup and model-provider presets. Bring your own API key.
- Cross-app tools, local PP-OCRv6 tiny OCR and coordinate actions.
- Embedded and floating virtual-display previews with manual takeover and agent handoff.
- Optional local tool-call logs and provider-reported token usage.
- Bright Cobalt identity and a focused task-first interface; English and Simplified Chinese UI, following the system by default.

**Downloads:** Choose `arm64-v8a` for most current Android phones. Choose `universal` for other CPU architectures. SHA-256 checksums are included.

**Requirements:** Android 11+ and Wi-Fi for built-in activation; Developer options and Wireless debugging authorization; a compatible model API key. Android 10 requires USB development activation.

This is an early preview, validated on a Pixel 6. Some apps restrict virtual displays. Model requests use your configured provider; this is not fully offline. Sensitive-action detection is heuristic. Keep the task visible and use takeover or stop when needed.
