# 自主执行与运行日志

普通点击、输入、滚动和导航自动执行。本地 `SensitiveActions` 依据实际节点与页面文字识别支付、删除、发送发布、安全授权等敏感动作，要求一次性确认；这是启发式识别，不能保证覆盖所有应用的自绘控件与未知文案。模型不能自行批准。密码与验证码输入继续手动处理。

设置中的「保留运行日志」默认开启，关闭立即停止新增，已有日志保留。新增「日志」页，可查看运行明细、刷新或清空。日志是 App 私有目录中的 JSONL，每次最多 512 KB，保留最近 20 次；不保存 API Key、Authorization、完整模型请求、原始界面节点或截图。工具输入参数属于日志内容。配置密钥在序列化前递归脱敏，包含引号与反斜线的密钥也覆盖。

每次运行关联步骤号、工具名称和参数、设备结果、审批、读屏与网络错误、耗时，以及模型返回的原始 `usage`。输入、输出和合计 token 可累计；缓存和推理等细分字段保留原值。未返回用量明确标记，不估算为零。连接测试也写日志，且不会执行模型返回的设备动作。

读屏会暂时隐藏悟空悬浮条；根节点短暂缺失时等待、清缓存，并尝试恢复一次 UiAutomation 连接。错误不再直接断言手机锁屏。执行仍核验当前包名和指纹，仅在驱动明确表示「界面已更新，本次操作未执行」时重新观察规划，最多连续三次。网络中断或结果未知不自动重放。
