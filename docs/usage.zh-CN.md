# 悟空使用说明

悟空是 Android 个人 AI 助手。用一句话描述目标，模型通过手机控件、截图/OCR 和 JS 短流程执行任务。当前为早期预览版，执行前请阅读[免责声明](../DISCLAIMER.md#简体中文)。

## 安装与首次配置

1. 从 [GitHub Releases](https://github.com/linkecoding/wukong/releases)下载 APK。大部分手机选择 arm64-v8a，其他支持的架构选择 universal。发布包附有 SHA-256 校验文件；main 的版本号不表示同名 APK 已发布。
2. 准备 Android 11+ 手机、已连接的 Wi-Fi、自有模型 API Key 和余额。Android 10 仅支持开发电脑 USB 激活。
3. 打开悟空，输入任务并发送。准备未完成时会进入向导，任务草稿会保留。
4. 选择服务商，填写 API Key 和模型 ID。点下拉箭头尝试获取模型列表，不支持列表的接口可以手动输入。测试保存不会执行手机任务，也不会自动返回上一页。可在该页右上角清除配置。
5. 按向导开启开发者选项和无线调试，在系统中选择“使用配对码配对设备”。保持配对弹窗开启，通过悟空通知提交六位配对码；配对端口与连接端口不同。发现失败时使用“连接遇到问题”中的手动配置。
6. 授予悬浮控制权限，等待执行引擎连接。回到会话检查任务并再次发送，准备完成不会自动执行。

悟空内置无线 ADB 与 app_process 执行引擎，不需要 root、无障碍服务或外部辅助 App。App 默认跟随系统语言，也可在设置中切换中英文。重启手机或无线调试状态变化后，可能需要重新连接。

## 任务怎么写

写清楚应用、目标、范围和停止条件，例如：

- “在文件管理器的下载目录找名称包含发票的 PDF，列出找到的文件名，停在列表页。”
- “打开计算器，计算三件 128 元加两件 59 元，按原价 85% 支付，算出 500 元剩多少。”
- “在系统设置查看 Android 版本、安全补丁日期和存储使用量，只读取，不修改设置。”

需要相关应用、内容和账号已准备好；模型可能判断错误。跟进任务可直接在当前会话提出，新会话不带入旧会话上下文。进行中的任务不会因 App 重启而被静默重放。

## 执行屏幕与接管

会话输入框下方的“执行选项”可选择手机主屏或虚拟屏。起始应用支持搜索选择，只决定从哪里开始，不限制后续操作范围。选择虚拟屏后等待就绪，再发送任务。

任务卡中的“查看画面”可展开内嵌预览。悟空切后台时显示浮窗，回到前台时收起。拖动顶部移动浮窗，拖动角落缩放，大小和位置会保存。关闭浮窗仅隐藏预览，任务继续；回到悟空再切后台可恢复。

点“接管”暂停 Agent 后，可触摸、滑动预览，用返回和桌面按钮导航；内嵌接管视图还支持向焦点输入框发送文字。点“交还 Agent”后重新读屏继续。停止任务不能撤销已发生的操作。部分应用限制虚拟屏或受保护画面，可尝试主屏执行。

普通操作自主执行，任务需要的发送、发布和分享也可能自动完成；被识别的支付转账、删除文件、清除数据等高危操作需要确认。识别不能覆盖所有风险，密码、验证码及受保护界面由你手动处理。

## 历史、日志和反馈

从任务卡或侧边抽屉的历史进入“执行详情”，查看结果、工具步骤与模型返回的 Token 用量。若服务商不返回用量，则无法保证完整统计。

需要排障时，先在设置开启保留日志，再复现问题。在这次运行详情右上角选择“导出本次日志”，保存或分享 ZIP。包内包含 `events.jsonl` 和 `manifest.json`，不含模型配置密钥和截图，但可能有私人任务、界面文本、参数和结果，提交前请检查。未保留的旧日志无法事后补回。清空历史和日志位于相应右上角菜单。

反馈请提供 App/Android 版本、机型、模型 ID、主屏/虚拟屏、复现目标与预期/实际结果。[提交问题](https://github.com/linkecoding/wukong/issues)，请勿上传 API Key、密码、配对码或私人账号信息。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 激活失败 | 检查已连接 Wi-Fi、无线调试和系统配对授权；区分配对端口与连接端口。系统重启或切换网络后可能需要重新连接。 |
| 模型 401/403 | 检查 Key、权限、余额和模型可用性。 |
| 模型 404 | 核对服务商 Base URL 与模型 ID。普通模式会追加 `/chat/completions`，仅完整接口地址使用“使用完整请求地址”；Base URL 不要求特定路径结尾。 |
| 无法获取模型列表 | 兼容接口不一定实现模型列表，手动填写支持工具调用的模型 ID。 |
| 虚拟屏空白或应用跑到主屏 | 可能是应用多屏/单任务限制或受保护内容，接管检查或改用主屏。 |
| 任务结果不对 | 检查真实页面和运行详情。完成核验不能证明任意任务正确；导出脱敏日志反馈。 |
| 正式包无法覆盖调试包 | 两者签名不同。不要为此直接卸载丢失数据；先阅读[签名说明](releasing.md)。同一正式签名的新版本可覆盖旧正式版。 |

OCR 在本机运行，模型推理由你配置的服务商完成，相关任务和页面内容会发送给该服务，可能产生 API 费用。详细数据范围与限制见[免责声明](../DISCLAIMER.md#简体中文)。
